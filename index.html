Kết nối Deplao & Cấp API Key Hàng Hóa

Kết nối 1 chiều (Deplao → NKiot): Deplao dùng API Key để đọc thông tin & hình ảnh hàng hóa từ NKiot

Thông số kết nối nhập vào Deplao Chỉ đọc 1 chiều · An toàn
Deplao kết nối vào NKiot qua Địa chỉ NKiot và API Key bên dưới để lấy danh sách hàng hóa, máy/IMEI và hình ảnh thực tế. NKiot hoàn toàn không can thiệp hay gửi thao tác nào sang Deplao.
Thiết lập API Key mới cho Deplao

API Key chỉ cấp quyền đọc thông tin hàng hóa và hình ảnh của chi nhánh đã chọn. Chỉ dán API Key vào phần cài đặt ứng dụng Kho hàng NKiot trên Deplao; thu hồi API Key sẽ ngắt kết nối ngay lập tức.

✅ Tạo API Key thành công! Hãy sao chép và dán vào Deplao ngay bây giờ
Vì lý do an toàn, mã API Key đầy đủ chỉ hiển thị một lần duy nhất. Nếu đánh mất, bạn chỉ cần thu hồi và tạo API Key mới.
Tên kết nối Mã API Key Chi nhánh Hạn dùng Lần đọc cuối Trạng thái Thao tác
📖 Quy trình kết nối từ Deplao vào NKiot (3 bước)
Bước 1: Tạo API Key trên NKiot
Sao chép Địa chỉ NKiot ở trên và bấm + Tạo API Key mới cho chi nhánh cần đồng bộ.
Bước 2: Nhập vào Deplao
Trên Deplao, mở cài đặt ứng dụng Kho hàng NKiot, dán Địa chỉ NKiot và API Key (nk_live_...) rồi lưu lại.
Bước 3: Tra cứu hàng hóa từ Deplao
Deplao tự động gọi API chỉ đọc của NKiot để lấy thông tin sản phẩm, giá bán, tồn kho và ảnh máy.
1. Danh sách hàng hóa: GET /api/v1/open/products?in_stock=true (Header: Authorization: Bearer nk_live_...)
2. Chi tiết & máy/IMEI: GET /api/v1/open/products/:code
3. Hình ảnh hàng hóa: GET /api/v1/open/media/:id
